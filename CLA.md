- **Individuals:** tick the CLA checkbox in the pull request template. Ticking it in a pull request accepts this agreement for the Contributions in that pull request and for every later Contribution you Submit. The pull request is kept as the record of your acceptance.
- **Entities:** contact the maintainers (see `SECURITY.md` for the channel) to sign an entity agreement that lists the people authorised to contribute on the entity's behalf.

Commits still need the DCO sign-off (`git commit -s`), which certifies where each change comes from.

To keep the record, the Project Steward processes your name, username and email address as they appear in the pull request and the commit history. The legal basis is the performance of this agreement and the legitimate interest in proving the origin of the code. The data is kept for as long as the Contribution is distributed.
